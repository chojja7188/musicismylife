# ADR 0003: 타임라인과 곡 전환

- 상태: 부분 대체됨 · 초기 채택 2026-11-16, 화면 표현은 [ADR 0005](0005-visual-behavior.md) 참고

## 결정
- 곡 i는 영상 `S_i`초에 시작해 `d_i = 끝 - 시작`초 재생. `S_{i+1} = S_i + d_i - F` (F = 크로스페이드, 기본 1.5초).
- 소리: 곡마다 GainNode. 첫 곡 페이드 인 0.3초, 이후 F초 선형 크로스페이드, 마지막 곡 F초 페이드 아웃.
- 화면: 전환 비율 k(smoothstep)로 배경·글로우·스펙트럼은 알파 교차, 커버·글자는 알파 + 옆으로 슬라이드(앞 곡 왼쪽으로 나감, 새 곡 오른쪽에서 들어옴).
- 영상 시작 0.4초 검은 화면에서 페이드 인, 끝 F초 페이드 아웃.
- 구간은 F의 2배보다 길어야 한다(아니면 에러 표시). 끝을 비우면 곡 끝까지. 총합이 1분을 넘으면 "영상 만들기"를 누를 때 확인창으로 알린다.
- 시계는 `AudioContext.currentTime` 하나로 소리·화면을 맞춘다.
- 곡이 2개 이상이면 끝에 5초 곡 목록 화면(`plan()`의 `O`)을 붙인다. 그동안 마지막 곡 소리가 이어서 나오고(원곡이 남아 있으면), 커버·글자는 0.6초 동안 사라지고 목록이 위에서부터 하나씩 나온다. 1분 확인은 이 5초까지 포함해 계산한다.

## 후속 변경

현재 목록 화면 표현은 [ADR 0005](0005-visual-behavior.md)의 5곡 기준 불투명 페이지·0.45초 슬라이드를 따른다. 초기의 글로우와 커버 소리 반응은 제거됐다. 타임라인과 목록 5초는 유지하며, [총시간 예시](../../README.md#총시간과-마지막-곡-목록)를 참고한다. 곡별 GainNode에는 [ADR 0006](0006-automatic-volume-matching.md)의 자동 음량 보정도 적용한다.
