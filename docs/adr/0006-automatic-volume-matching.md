# ADR 0006: 선택 구간 기준의 자동 음량 맞춤

- 상태: 채택 · 2026-11-17

## 맥락

MP3마다 음량이 달라 여러 곡을 이어 붙이면 볼륨 차이가 들렸다. 원본 파일을 바꾸거나 사용자가 곡마다 수동 조정하지 않고, 외부 의존성 없이 차이를 줄이고 싶었다.

## 결정

- 디코드한 AudioBuffer의 선택 구간을 100ms 블록으로 분석한다. 가장 큰 블록보다 20dB 넘게 작은 블록과 매우 작은 신호는 평균에서 제외한다.
- 유효 RMS 목표는 -18 dB, 증폭 상한은 4배(약 +12 dB). 곡 안의 강약을 유지하도록 곡마다 고정 게인을 적용한다.
- 샘플 피크가 -1 dBFS를 넘지 않도록 필요하면 모든 곡의 게인을 같은 비율로 낮춘다. 선형 크로스페이드와 함께 사용한다.
- 마지막 곡은 목록 화면에서 이어지는 구간까지 분석한다. 구간별 분석은 AudioBuffer를 키로 캐시한다.
- 미리듣기와 녹화가 같은 보정 경로를 사용하며, 원본 MP3는 수정하지 않는다. 기본 적용하고 별도 토글은 두지 않는다.

## 결과와 한계

피크만 맞추는 방식보다 평균 음량 차이를 줄이고, 무음 때문에 곡이 과도하게 커지는 것을 줄인다. 다만 정식 LUFS·주파수 가중·트루피크 측정이나 리미터는 아니다. 음색·편곡 차이, 증폭 상한, 전체 피크 여유 때문에 체감 음량과 목표값을 완전히 보장하지 않는다.

한 곡만 미리듣는 경우에는 전체 재생과 분석 범위(목록 없음)·전체 피크 여유가 달라 보정 게인이 달라질 수 있다.

`tests/volume.cjs`와 실제 헤드리스 녹화로 확인했다. 진폭이 10배 다른 합성 곡 두 개가 녹화 후 모두 평균 -18.0 dB로 측정됐다.
