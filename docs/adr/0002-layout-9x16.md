# ADR 0002: 9:16 레이아웃 (1080×1920 캔버스)

- 상태: 부분 대체됨 · 초기 채택 2026-11-16, 화면 표현은 [ADR 0005](0005-visual-behavior.md) 참고

## 결정
- 위: 시리즈 제목(선택) + 곡 번호 `01 / 05`. 전환 중에도 고정.
- 가운데: 커버 600px(x=150, y=400), LP는 오른쪽으로 180px 빠져나와 33⅓rpm 회전. 커버는 베이스/비트에 맞춰 살짝 커짐.
- 아래: 제목(2줄), 가수(커버 색), 진행바(원곡 기준 위치/전체 길이), 대칭 스펙트럼, 계정 이름.
- 배경: 커버 블러(어둡게). 커버 뒤 글로우, 비트마다 퍼지는 링.
- 가사 없음(계정 방향).

## 결과
제페토 캐릭터를 넣을 자리는 아직 없다. 넣게 되면 새 ADR로.

## 후속 변경

2026-11-17의 [ADR 0005](0005-visual-behavior.md)가 커버 반응·제목 맞춤·배경 효과를 부분 대체한다. 위 결정은 초기 구성이며, 현재 커버는 고정 크기이고 링·글로우는 없다.
