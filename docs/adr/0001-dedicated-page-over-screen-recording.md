# ADR 0001: 오버레이 화면 녹화 대신 전용 숏폼 메이커 페이지

- 상태: 채택 · 2026-11-16

## 맥락
`../dj/overlay.html`(방송용 1:1 음악 오버레이)을 켜고 음악을 틀며 화면 녹화하는 방법을 먼저 고려했다.
문제: 1:1 레이아웃, media-control·BlackHole·OBS 세팅 필요, 구간 자르기·곡 사이 페이드는 수동 편집, 녹화 중 프레임 드랍/알림.

## 결정
- `index.html` 한 파일. mp3를 직접 디코드(Web Audio)하고 캔버스에 그리며 `MediaRecorder`로 녹화.
- 오버레이의 비주얼 코드(`palette`, `bands`, 비트 감지, LP·글로우·링)를 캔버스용으로 옮겨 재사용.
- CapCut 템플릿(시리즈마다 수작업), Remotion 등 영상 프레임워크(이 규모엔 무거움, npm 필요)는 기각.

## 결과
- 설치·서버 없이 크롬으로 파일만 열면 된다.
- 녹화는 실시간(1분 영상 = 1분), 탭을 띄워 둬야 한다.

## 후속 변경

초기에는 비트·글로우·링도 가져왔으나, 현재 숏폼에서는 제거했다. 현재 화면 표현은 [ADR 0005](0005-visual-behavior.md)를 따른다.
