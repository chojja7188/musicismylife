# ADR 0005: 커버는 고정하고 스펙트럼·LP로 움직임을 표현

- 상태: 채택 · 2026-11-17
- [ADR 0002](0002-layout-9x16.md)의 커버 반응·제목·배경 효과와 [ADR 0003](0003-timeline-and-transitions.md)의 목록 화면 표현을 부분 대체한다. 캔버스 크기·커버 위치·음악 타임라인은 유지한다.

## 맥락

사용자는 링 파동, 밝기가 변하는 커버 주변 빛, 커버가 통통 튀는 확대/축소를 원하지 않았다. 스펙트럼은 처음에는 항상 꽉 차 보였고, 포화를 수정한 뒤에는 반응이 약하다는 피드백이 있었다. 제목은 가능한 한 줄로, 목록은 5곡을 기준으로 별도 페이지처럼 보이길 원했다.

## 결정

- 커버 크기를 고정하고 검은 그림자만 둔다. 링·컬러 글로우·박자 확대와 사용하지 않는 비트 분석을 제거한다. LP 회전과 스펙트럼 높낮이는 유지한다.
- 스펙트럼은 실제 주파수 dB를 -72~-12 범위로 매핑해 대역 내 값을 제곱 평균한 뒤 제곱근을 구한다. 지수 1.5·최대 높이 .9, 상승 .7·하강 .22로 보간한다.
- 기존 byte 값은 기본 분석 범위 상한에서 일찍 포화됐고, 최댓값 선택·추가 증폭·고음 가중치가 이를 키웠다. 이 계산으로 되돌리지 않는다.
- 메인 제목은 76~56px 안에서 한 줄을 우선한다. 최소 크기에도 안 맞으면 65px 두 줄로 표시한다. 목록 제목에도 같은 원칙을 적용한다. 두 줄 초과는 말줄임한다.
- 목록은 5곡 기준 행 크기, 5곡 초과 시 축소. 불투명한 배경의 별도 페이지가 0.45초 동안 오른쪽에서 들어온다. 시리즈 제목·계정 이름은 고정한다.
- 목록은 마지막 곡 선택 구간 이후 5초라는 기존 타임라인을 유지한다. 이 시간은 표시 총시간에 포함된다.

## 결과

화면은 차분하게 유지하면서 LP와 스펙트럼으로 음악의 움직임을 보여준다. 제목은 아주 길면 여전히 두 줄·말줄임이 필요하다. 실제 음악의 스펙트럼 반응은 사용자 피드백에 따라 추가 조정할 수 있다.

형제 DJ 프로젝트에는 스펙트럼 개선만 함께 적용했다. 링·빛·커버 확대 제거는 숏폼에만 해당한다.

## 녹화 첫 프레임 보완 (2026-11-17)

사용자가 제공한 영상 두 개의 첫 프레임에 음악 미리보기 화면이 들어 있었다. 캡처 스트림 생성 전과 녹화 시작 직전에 검정색을 채우고, 오디오 준비 대기 중에도 검정색을 유지한다. 시작 페이드와 기존 총시간은 바꾸지 않는다. 앱이 별도로 선택하는 썸네일을 강제하는 기능은 아니다.
