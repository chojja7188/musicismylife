## 자동 음량 맞춤 (2026-11-17)
- 기본 적용: 선택 구간의 100ms 블록 RMS를 분석하고, 상대적으로 작은 무음 블록을 제외해 -18 dB RMS에 맞춘다. 마지막 곡은 아웃트로에 쓰이는 소리까지 포함한다.
- 최대 증폭은 약 +12 dB. 샘플 피크가 -1 dBFS를 넘지 않도록 필요하면 모든 곡을 같은 비율로 낮춘다. 선형 크로스페이드와 미리듣기·녹화 모두 같은 게인을 사용한다. 원본 파일은 바꾸지 않는다.
- 정식 LUFS/트루피크 측정은 아니므로 음색·편곡이 다른 실제 곡의 체감 음량은 약간 다를 수 있다. 매우 작은 곡은 증폭 제한 때문에 목표보다 작을 수 있다.
- 검증: `node tests/volume.cjs` (입력 음량 차이, 선택 구간, 무음, 피크 보호). 실제 헤드리스 크롬 녹화에서 진폭 0.06/0.6 두 곡 모두 평균 -18.0 dB, 1080×1920 H.264/AAC 확인.
- GitHub Pages 배포 대상: 자동 음량 맞춤 기본 적용.
