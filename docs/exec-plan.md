## 시간 계산에서 주의할 점

표시 총시간은 `Σ선택 구간 − 크로스페이드×(곡 수−1) + 목록 화면`이다. 목록은 2곡 이상일 때 5초이며, 표시값에 이미 포함된다.

- 5곡 × 10초, 크로스페이드 1.5초 → 음악 화면 44초 + 목록 5초 = **49초**.
- 5곡 × 11초, 크로스페이드 1.5초 → 음악 화면 49초 + 목록 5초 = **54초**.
- 마지막 곡 `2:49~3:00` → 11초 재생 후 목록으로 전환. 목록 중에는 원곡의 남은 부분을 최대 `3:05`까지 이어서 재생한다. 원곡이 먼저 끝나면 나머지 목록 시간은 무음이다.
- 녹화 종료 타이머는 표시 총시간에 약 0.6초 여유를 더한다. 60초 초과 확인은 표시 총시간 기준이며 강제 제한은 아니다.

이 동작은 현재 사양이다. “입력한 끝 시간을 오디오 종료 시점으로 사용할지”는 아직 변경 요청이 없으므로 임의로 바꾸지 않는다.

## 검증 결과

| 범위 | 근거 | 확인한 내용 |
|---|---|---|
| 자동 음량 | `node tests/volume.cjs` | 서로 다른 입력 음량, 선택 구간, 무음, 샘플 피크 보호 |
| 스펙트럼·목록 | `node tests/visuals.cjs` | 중간 음량 반응, 최대 높이 여유, 한 주파수의 과도한 영향 완화, 감쇠, 5곡 기준·초과 배치 |
| 제목 | `node tests/titles.cjs` | 짧은 제목, 한 줄 축소, 긴 제목 두 줄, 띄어쓰기 없는 제목 |
| 실제 영상 | 임시 사본 + 헤드리스 크롬 + ffprobe/ffmpeg | 1080×1920 H.264/AAC MP4, 음성 포함, 곡 전환·목록 전환·페이드 |
| 음량 보정 결과 | 진폭 0.06/0.6 합성 곡을 녹화해 `volumedetect` | 두 곡 모두 평균 -18.0 dB |
| 화면 | 임시 사본의 캔버스 이미지 및 녹화 | 5곡 목록, 불투명 페이지 전환, 한 줄·두 줄 제목, 커버 효과 제거 후 화면 |
| 일시저장 | 앞선 헤드리스 저장→재접속 검사 | 파일·입력값 복원 |

브라우저 검증용 사본·서버·이미지·녹화 파일은 임시 폴더를 사용했다. 재사용 가능한 녹화 테스트 도구는 저장소에 포함되어 있지 않다. `tests/titles.cjs`의 글자 폭은 단순화한 테스트용 값이므로 실제 글꼴 검증은 브라우저 화면으로 보완했다.

사용자가 실제 곡의 반응·재생 길이를 확인하며 피드백했으나, 실제 MP3/커버의 최종 녹화와 휴대폰·각 플랫폼 업로드를 포함한 전체 과정은 별도 검증 완료로 간주하지 않는다. 이 프로젝트는 OBS를 필요로 하지 않는다.

## 알려진 한계

- 실시간 녹화이므로 탭을 띄워 두어야 한다. 화면 잠금·앱 전환·기기 성능에 영향을 받는다.
- 녹화 파일은 종료 여유 때문에 표시 총시간보다 조금 길 수 있다.
- 음량 보정은 유효 RMS와 샘플 피크 기준이다. LUFS/트루피크 측정이 아니며, 음색 차이·증폭 상한 때문에 체감 음량이 완전히 같지는 않다.
- 일시저장은 클라우드 동기화가 아니다. 기기·브라우저·주소별로 다르며 브라우저 정책이나 데이터 삭제로 사라질 수 있다.
- “새로 시작” 버튼이 없어 처음부터 하려면 카드를 하나씩 지워야 한다.
- 실제 기기의 최종 녹화와 제페토·인스타·유튜브 업로드 호환은 추가 확인이 필요하다. 플랫폼의 상업 음원 저작권 감지는 별개다.
