# 음악 숏폼 메이커

MP3와 앨범 커버, 사용할 구간을 넣어 제페토·인스타·유튜브용 세로 음악 영상을 만듭니다. 가사는 넣지 않고, 커버·회전하는 LP·스펙트럼으로 음악을 소개합니다.

## 열기

[숏폼 메이커 사용하기](https://chojja7188.github.io/musicismylife/)

핸드폰도 같은 주소로 사용합니다. 맥에서는 서버나 설치 없이 로컬 파일을 열어도 됩니다.

```bash
open -a "Google Chrome" index.html
```

## 사용 순서

1. 곡마다 MP3와 커버 이미지를 넣습니다. 커버는 곡 카드를 클릭하고 `⌘V`로 붙여넣을 수도 있습니다.
2. 제목·가수와 시작·끝을 확인합니다. 시간은 `1:12` 또는 `72`처럼 입력합니다. 끝을 비우면 원곡 끝까지 사용합니다.
3. 시리즈 제목·계정 이름·크로스페이드를 설정합니다. 시리즈 제목을 비우면 영상에 나오지 않습니다.
4. `이 구간만` 또는 `미리보기`로 확인한 뒤 `영상 만들기`를 누릅니다.
5. 녹화가 끝날 때까지 탭을 화면에 띄워 둡니다. 완료되면 영상이 다운로드됩니다. `정지`를 누르면 녹화가 취소됩니다.

파일 이름이 `가수 - 제목.mp3` 형식이면 비어 있는 제목·가수가 자동으로 채워집니다. 입력값과 원본 파일은 해당 브라우저에 일시저장되어 새로고침 시 복원됩니다. 원본 MP3는 수정하지 않습니다.

## 총시간과 마지막 곡 목록

**표시된 총시간에는 마지막 목록 화면 5초가 이미 포함됩니다.** 크로스페이드에서는 앞뒤 곡이 겹치므로 전체 길이가 줄어듭니다.

```text
총시간 = 각 곡의 선택 구간 합계 − 크로스페이드 × (곡 수 − 1) + 목록 화면
목록 화면 = 2곡 이상이면 5초, 1곡이면 없음
```

| 설정 | 음악 화면 | 목록 화면 | 표시 총시간 |
|---|---:|---:|---:|
| 5곡 × 10초, 크로스페이드 1.5초 | 44초 | 5초 | 49초 |
| 5곡 × 11초, 크로스페이드 1.5초 | 49초 | 5초 | 54초 |

마지막 곡의 **선택 구간이 끝나면** 목록 화면으로 바뀝니다. 목록 화면에서도 음악이 이어지도록, 원곡에 남은 부분이 있으면 입력한 끝 시간 이후를 최대 5초 더 재생합니다. 예를 들어 마지막 곡을 `2:49~3:00`으로 설정하면, 목록 화면에서 최대 `3:05`까지 이어집니다. 원곡이 먼저 끝나면 소리도 먼저 끝납니다.

녹화 종료에 약 0.6초의 여유를 두므로 저장 파일 길이는 표시 총시간보다 조금 길 수 있습니다. 선택 구간은 크로스페이드의 2배보다 길어야 합니다. 총시간이 60초를 넘으면 녹화 전 확인창이 나옵니다.

## 현재 화면과 소리

- 곡마다 선택 구간을 분석해 음량 차이를 자동으로 줄입니다. 미리듣기와 녹화에 모두 적용됩니다. 음악마다 음색이 달라 체감 음량이 완전히 같지는 않을 수 있습니다.
- 제목은 글자를 조금 줄여 한 줄로 우선 표시하고, 너무 길면 두 줄로 표시합니다. 두 줄에도 다 담기지 않으면 말줄임표가 나옵니다.
- 마지막 목록은 5곡 기준 크기이며, 5곡을 넘으면 전체가 들어가도록 줄입니다. 반투명 덮개가 아닌 별도 불투명 화면으로 전환됩니다.
- 커버 크기는 고정이며 주변에서 빛나는 효과·커버 확대/축소·링 파동은 없습니다. LP 회전과 소리에 반응하는 스펙트럼은 유지합니다.

## 알아둘 점

- 영상은 실시간으로 녹화됩니다. 탭을 가리거나 핸드폰 화면을 끄고 다른 앱으로 이동하면 영상이 멈출 수 있습니다.
- 일시저장은 기기·브라우저·주소별로 다릅니다. 로컬 파일과 배포 사이트도 별도입니다. 브라우저 데이터 삭제나 저장 공간 정책에 따라 사라질 수 있습니다.
- 기본 출력은 1080×1920, 30fps입니다. 브라우저가 지원하면 MP4로, 그렇지 않으면 WebM으로 저장합니다.
- 제페토·인스타·유튜브에 실제로 업로드했을 때의 호환성은 아직 별도 확인이 필요합니다. 상업 음원은 플랫폼의 저작권 감지 대상이 될 수 있습니다.

## 개발·검증·배포

외부 라이브러리, npm, 빌드 과정 없이 `index.html` 한 파일로 동작합니다. 테스트만 Node.js를 사용합니다. 저장소 루트에서 실행합니다.

```bash
node tests/volume.cjs
node tests/visuals.cjs
node tests/titles.cjs
git diff --check
```

GitHub Pages는 `main` 브랜치 루트를 배포합니다. `git push origin main` 후 GitHub Actions의 배포 성공을 확인합니다. 보통 1~2분 걸립니다.
